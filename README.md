# PDF Merger & Watermarker

A Python project demonstrating file handling and PDF manipulation using the `pypdf` library.

## Features
- Merge multiple PDF files into one (`super.pdf`)
- Add a watermark to each page (`watermarked.pdf`)
- Simple, beginner‑friendly code for learning file handling

## Installation
```bash
pip install pypdf
## To merge the pdf's we run this command in bash/command prompt
python merge_pdf.py file1.pdf file2.pdf file3.pdf
## to add watermark
python watermark_pdf.py
